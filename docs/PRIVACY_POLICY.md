# Privacy Policy for Evil Eye Privacy Policy Analyzer

Effective date: May 5, 2026

Evil Eye Privacy Policy Analyzer is a Chrome extension that helps users understand privacy policy language, page tracker activity, and optional per-site protection controls while browsing.

## Summary

The extension analyzes the current website in the browser. It does not send browsing history, page text, privacy policy text, tracker results, form values, or protection settings to a developer-operated server. The extension does not sell user data and does not use user data for advertising.

## Data the extension handles

The extension may process the following data locally in the browser to provide its user-facing features:

- Current website URL, tab URL, page title, page links, and visible page text needed to find and analyze a privacy policy.
- Privacy policy text fetched directly from the website being analyzed or from a known policy URL for that domain.
- Page tracker signals, including request domains, known tracker service matches, third-party script and iframe signals, browser storage key names, ad-like elements, and data-entry field labels.
- Extension activity and settings, including cached scan results, toolbar icon state, per-site protection choices, and counts of blocked tracker or ad-like page items.

The extension does not intentionally collect typed form values, passwords, payment card numbers, private messages, files, or account credentials.

## How data is used

Handled data is used only to:

- Find the relevant privacy policy for the current website.
- Produce local privacy policy highlights and evidence snippets.
- Detect tracker and ad-like activity on the current page.
- Update the extension popup and toolbar icon.
- Apply optional protection settings chosen by the user for the current site.
- Improve reliability of the scan and protection features within the extension.

## Network activity

The extension may fetch a privacy policy page directly from the website being analyzed when the current page links to that policy or when a known policy registry entry exists for the domain. These requests go to the policy source website itself.

The extension does not use a hosted analyzer, remote artificial intelligence service, analytics endpoint, advertising endpoint, or developer-operated data collection endpoint. The extension package contains its analysis logic and does not load remote code.

## Data sharing and sale

The extension does not sell user data. The extension does not share browsing activity, page content, privacy policy text, tracker results, or protection settings with third parties.

## Local storage

The extension uses Chrome extension storage to save local scan cache, toolbar state, per-site protection choices, and protection activity counts. Users can clear this data by removing the extension or clearing extension storage through Chrome.

## Permissions

The extension requests permissions needed to scan the active website, detect tracker activity, fetch linked privacy policies, update the toolbar icon, and apply optional per-site protection controls. Permission justifications are documented in the Chrome Web Store submission notes for this project.

## Chrome Web Store Limited Use

The extension's use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide and improve the extension's single purpose: helping users understand website privacy policy risks and page tracker activity, with optional per-site protection.

## Changes

This policy may be updated as the extension changes. Material changes should be reflected in the Chrome Web Store listing and in this policy before publication.

## Contact

For privacy questions, use the support contact provided in the Chrome Web Store listing.
